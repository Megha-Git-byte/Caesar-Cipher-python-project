# Caesar Cipher Python Project

A command-line Python application that encrypts and decrypts text using the classic Caesar Cipher algorithm. It handles shifts, preserves numbers, spaces, and symbols, and allows the user to continuously cycle through messages.

## 🚀 How to Run
1. Make sure you have Python installed.
2. Download both `main.py` and `art.py` into the same folder.
3. Open your terminal/command prompt in that folder and run:
   ```bash
   python main.py
   ```

## 🛠️ Features Included
- **Custom ASCII Art:** Displays a styled logo at startup.
- **Bi-directional Cipher:** Supports both `encode` and `decode` paths.
- **Symbol & Number Handling:** Safely keeps spaces and special characters intact without altering them.
- **Infinite Loop Option:** Asks the user if they want to restart or exit when done.
